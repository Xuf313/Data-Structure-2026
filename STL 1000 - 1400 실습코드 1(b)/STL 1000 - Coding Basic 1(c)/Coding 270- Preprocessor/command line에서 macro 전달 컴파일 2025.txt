g++ 컴파일 시 #define으로 정의된 매크로를 전달하려면 컴파일 명령어에 -D 옵션을 사용합니다. 

예를 들어, 소스 코드에서 MY_DEFINE 매크로를 사용하고 있다면 
g++ -DMY_DEFINE=1 your_code.cpp 와 같이 컴파일하여 사용할 수 있습니다. 

-D 옵션 사용법 
-D: 매크로를 외부에서 정의할 때 사용합니다.
-D 뒤에 매크로 이름과 값을 지정:

-DMY_DEFINE: 매크로 MY_DEFINE을 정의하지만, 특정 값을 할당하지는 않습니다. 
  이 경우 MY_DEFINE는 존재하지만 그 자체로 사용됩니다.
  
-DMY_DEFINE=1: 매크로 MY_DEFINE을 정의하고 값을 1로 할당합니다.

-DMY_DEFINE="Hello": 매크로 MY_DEFINE을 정의하고 문자열 값 "Hello"를 할당합니다.
